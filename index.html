如何免费获取 API Key？第一次用看这里
💡 阿里云百炼对新用户免费：每个文本模型送 100 万 token，有效期 90 天，个人用够很久。用完会自动转按量付费，可在控制台开启「免费额度用完即停」避免超额扣费。
注册并登录阿里云账号，完成实名认证。
开通服务：打开 百炼产品页， 点「免费体验 / 立即开通」，同意协议，把「百炼平台」和「大模型服务」都开通。模型服务没开通时，创建 Key 的按钮是灰的。
进入 百炼控制台， 右上角地域选「华北2（北京）」，左侧菜单找到 API-Key，点「创建 API-Key」，业务空间选默认、权限选全部，确定。
弹窗会显示完整的 Key（sk- 开头），马上复制——关闭后就看不到明文了，丢了只能重置或新建。把它粘到下面的输入框即可。
🔒 Key 等于你的账号调用权限，别发给别人、别提交到代码仓库或截图外传。本页只在你的浏览器内存里临时使用它，不会保存或上传。
